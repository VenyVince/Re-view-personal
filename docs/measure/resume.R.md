# 이력서 R 초안

## 1. 작성 상태

미작성. 동시성, 추천 SQL, 검색 SQL 측정값이 없다. 문장을 만들지 않는다.

근거로 쓸 수 있는 파일:

- `docs/measure/result.concurrency.md`
- `docs/measure/result.recommend.md`
- `docs/measure/result.search.md`
- `docs/measure/result.summary.md`

## 2. 후보 문장

| 항목 | 문장 | 근거 | 이력서 반영 |
|---|---|---|---|
| 포인트 동시성 정합성 | 미작성 | 측정값 없음 | 미정 |
| 상품 추천 SQL | 미작성 | 측정값 없음 | 미정 |
| 리뷰 추천 SQL | 미작성 | 측정값 없음 | 미정 |
| 상품 검색 SQL | 미작성 | 측정값 없음 | 미정 |
| 리뷰 검색 SQL | 미작성 | 측정값 없음 | 미정 |

개선율, p95, 서비스 검색 정상 동작, Best 리뷰 중복 지급 방지 성공 횟수는 적지 않는다.
