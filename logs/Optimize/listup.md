## 공통 측정 항목

| 항목 | 의미 | 기록 예시 |
|---|---|---|
| 평균 응답 시간 | 여러 번 요청했을 때 응답 시간의 평균값 | `420ms` |
| p95 응답 시간 | 전체 요청 중 95%가 이 시간 안에 끝나는 값 | `780ms` |
| p99 응답 시간 | 전체 요청 중 99%가 이 시간 안에 끝나는 값 | `1200ms` |
| RPS | 1초에 처리한 요청 수 | `35 req/s` |
| DB 실행 시간 | API 요청 중 DB 쿼리에 걸린 시간 | `180ms` |
| 응답 payload 크기 | 클라이언트로 내려간 응답 데이터 크기 | `640KB` |
| 이미지 URL 생성 호출 수 | 응답 1회 동안 `presignedUrlGet`이 호출된 횟수 | `20회` |

## 보조 측정 항목

| 항목 | 의미 | 주로 필요한 경우 |
|---|---|---|
| 반환 row 수 | DB에서 조회된 row 수 | 리뷰 이미지 조인, 목록 조회 |
| SELECT 횟수 | 요청 1회 중 실행된 SELECT 수 | N+1 의심 구간 |
| 이미지 object key 수 | 응답에 포함된 이미지 key 수 | 이미지가 포함된 API |
| 이미지 URL 변환 총 시간 | 이미지 URL 생성에 걸린 전체 시간 | `presignedUrlGet` 반복 호출 구간 |
| 트랜잭션 유지 시간 | 트랜잭션이 열린 뒤 닫힐 때까지 걸린 시간 | 주문, 포인트 처리 |
| lock 대기 시간 | DB lock 때문에 기다린 시간 | `FOR UPDATE`, 재고 차감 |
